Política de Privacidade

Imprimir Gmail e Abas

Aplicativo: Imprimir Gmail e AbasÚltima atualização: 16 de outubro de 2026

O que o aplicativo faz

O aplicativo "Imprimir Gmail e Abas" é uma extensão para o Google Chrome. Ela permite que o usuário selecione e-mails no Gmail ou abas abertas contendo PDFs, agrupe os arquivos PDF encontrados em um único documento e abra automaticamente a tela de impressão do navegador.

Quais dados o aplicativo acessa

Para funcionar, a extensão solicita acesso de leitura à sua conta do Gmail (escopo gmail.readonly), usado exclusivamente para ler e formatar, para fins de impressão, os e-mails e anexos PDF que o próprio usuário selecionar:

  • Ler o conteúdo dos e-mails que o próprio usuário marcar manualmente na interface do Gmail;
  • Identificar e baixar os anexos em formato PDF desses e-mails;
  • Ler o conteúdo de abas do navegador que o usuário escolher processar, para identificar e extrair PDFs abertos nelas.

A extensão não acessa e-mails, anexos ou abas que o usuário não tenha explicitamente selecionado através dos botões da própria extensão.

Como os dados são usados

Os PDFs identificados são combinados localmente, no próprio navegador do usuário, em um único arquivo temporário, com a única finalidade de exibir a tela de impressão. Nenhum processamento ocorre em servidores externos.

Armazenamento

A extensão não armazena, não transmite e não compartilha o conteúdo de e-mails, anexos ou dados pessoais com terceiros, com o desenvolvedor ou com qualquer servidor externo. O arquivo PDF combinado é mantido apenas temporariamente na memória local do navegador (via chrome.storage.local) e é removido automaticamente logo após a tela de impressão ser aberta.

Compartilhamento com terceiros

Não há compartilhamento de dados com terceiros, redes de publicidade ou serviços de análise de uso. A única comunicação externa realizada é diretamente entre o navegador do usuário e os servidores oficiais do Google (Gmail API), usando a própria conta autenticada do usuário.

Conformidade com a Política de Dados do Usuário dos Serviços de API do Google

O uso e a transferência para qualquer outro aplicativo de informações recebidas das APIs do Google pelo "Imprimir Gmail e Abas" seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado (Limited Use). Os dados do Gmail são usados somente para fornecer a funcionalidade de impressão visível ao usuário, não são usados para publicidade, não são vendidos e não são lidos por humanos.

Permissões solicitadas

  • identity: para autenticação OAuth com a conta Google do usuário.
  • activeTab / tabs / scripting: para identificar PDFs nas abas abertas selecionadas pelo usuário.
  • storage: para manter temporariamente o PDF combinado até a impressão ser aberta.
  • gmail.readonly: para ler e-mails e anexos selecionados manualmente pelo usuário.

Direitos do usuário

O usuário pode revogar o acesso da extensão à sua conta Google a qualquer momento em myaccount.google.com/permissions, e desinstalar a extensão a qualquer momento pelo próprio navegador.
